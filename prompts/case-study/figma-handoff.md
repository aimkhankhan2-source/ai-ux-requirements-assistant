# Figma Handoff Specification

## Project

Smart Study Room Booking System

## Design Goal

Translate the AI-generated UX requirements into a clear, usable interface.

## Screen 1: Room Search

### Purpose
Help students quickly find available study rooms.

### Components

- Search bar
- Date selector
- Time selector
- Capacity filter
- Equipment filter
- Room availability cards

### Primary Action

Select a room.

---

## Screen 2: Room Details

### Purpose

Help students evaluate a room before booking.

### Components

- Room name
- Capacity
- Equipment
- Available time slots
- Booking button

### Primary Action

Book room.

---

## Screen 3: Booking Confirmation

### Purpose

Confirm the student's reservation.

### Components

- Room information
- Date
- Time
- Booking summary
- Confirm button

### Primary Action

Confirm booking.

---

## Screen 4: My Bookings

### Purpose

Allow students to manage existing reservations.

### Components

- Upcoming bookings
- Booking details
- Cancel booking
- Booking history

### Primary Action

Manage booking.

---

```text
Room Search
    ↓
